GOLD SCALPER PWA — PETUNJUK

Isi:
- Dashboard iPhone dengan grafik harga sintetis.
- Timeframe tampilan M1 dan M5.
- EMA 9/21, RSI 14, ATR 14.
- Saldo virtual dan riwayat simulasi.
- Service worker untuk cache/offline setelah kunjungan pertama.

PENTING:
Aplikasi ini hanya simulator edukasi. Harga dibuat acak di perangkat, bukan harga emas pasar.
Tidak terhubung ke MT5/broker, tidak menerima kredensial, dan tidak mengirim order.
Saldo dan hasil hanyalah angka simulasi, bukan hasil investasi.

CARA MEMASANG DI IPHONE:
1. File ZIP ini adalah paket sumber PWA, bukan IPA.
2. Agar bisa dipasang sebagai web app, file harus diunggah ke hosting statis yang mendukung HTTPS.
3. Setelah alamat HTTPS tersedia, buka alamatnya lewat Safari di iPhone.
4. Tekan tombol Share (kotak dengan panah ke atas) → Add to Home Screen → Add.
5. Buka ikon GOLD SCALPER dari Home Screen.

Catatan teknis:
- Service worker dan instalasi PWA memerlukan HTTPS (localhost untuk pengembangan).
- Jika file diubah, versi cache pada sw.js dapat dinaikkan agar perubahan baru dimuat.
- Paket ini belum di-host dan belum memiliki alamat web publik.
